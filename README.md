# cookiecutter-coursedocs

Cookiecutters for LaTeX course documents.

This repository collects several [Cookiecutter](https://cookiecutter.readthedocs.io/)
templates for course assessment documents maintained as `l3build` modules.
They are intended for generating reusable document projects for quizzes, exams,
and problem sets.

## Included templates

- [`amcquiz/`](./amcquiz/): auto-multiple-choice quiz template
- [`nyuquiz/`](./nyuquiz/): quiz template derived from the exam class
- [`exam/`](./exam/): exam template
- [`pset/`](./pset/): problem set template

## Using a template

Each template directory contains its own `README.md` with the variables,
generation details, and any template-specific testing notes.

Start by choosing the template that matches the document you want to create,
then follow the instructions in that template's README.
